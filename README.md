## ⚡ БЫСТРЫЙ СТАРТ (5 минут)

### 1. Скачайте `lumia-dental-final-6.html`

### 2. Замените 4 строки:
```
Строка 11:  https://lumia-dental.com.ua → ВАШ ДОМЕН
Строка 12:  /og-image.jpg → реальный путь
Строка 1593-1594: Instagram/Facebook → реальные URL
Строка ~2000: YOUR_GA4_ID → ваш Google Analytics ID
```

### 3. Загрузите на хостинг:
- GitHub Pages (бесплатно, easiest)
- Vercel (бесплатно, рекомендуется)
- Netlify (бесплатно, simple)
- Cpanel хостинг (если уже есть)

### 4. Загрузите 3 картинки в корень:
- `og-image.jpg` (1200×630px)
- `favicon.ico` (иконка для закладок)
- `apple-touch-icon.png` (для iPhone)

### 5. Проверьте сайт:
- Откройте домен в браузере
- Тестируйте форму контакта
- Откройте PageSpeed: https://pagespeed.web.dev
