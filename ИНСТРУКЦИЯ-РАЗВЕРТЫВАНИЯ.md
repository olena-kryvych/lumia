# 🚀 ИНСТРУКЦИЯ ПО РАЗВЕРТЫВАНИЮ LUMIA DENTAL

## ШАГИ ДО РАЗВЕРТЫВАНИЯ (5-10 минут)

### 1️⃣ **Подготовить изображения**

#### OG-превью (1200×630px)
1. Создайте или найдите изображение (размер: 1200×630px)
   - Может быть скриншот сайта + логотип
   - Или фото клиники + логотип
   - Формат: JPG или PNG (сжатый)
2. Назовите файл: `og-image.jpg`
3. Загрузите в корневую папку сайта

#### Favicon (16×16, 32×32, 64×64px)
1. Возьмите логотип Lumia (синий "Lumia.")
2. Сделайте 3 версии: 16×16, 32×32, 64×64px
3. Конвертируйте в `favicon.ico` (используйте favicon.io)
4. Загрузите в корневую папку сайта

#### Apple Touch Icon (180×180px)
1. Квадратный логотип размер 180×180px
2. Назовите: `apple-touch-icon.png`
3. Загрузите в корневую папку

### 2️⃣ **Заменить заглушки в HTML**

Откройте `lumia-dental-final-6.html` и замените:

#### А) Домен в og:url
Найдите (строка ~11):
```html
<meta property="og:url" content="https://lumia-dental.com.ua">
```
Замените на ваш реальный домен:
```html
<meta property="og:url" content="https://YOUR-DOMAIN.com.ua">
```

#### Б) OG-image путь
Найдите (строка ~12):
```html
<meta property="og:image" content="https://lumia-dental.com.ua/og-image.jpg">
```
Замените:
```html
<meta property="og:image" content="https://YOUR-DOMAIN.com.ua/og-image.jpg">
```

#### В) Посилання на соціальні мережі
Найдите (строка ~1593-1594):
```html
<a href="https://instagram.com" target="_blank" rel="noopener noreferrer">Instagram</a>
<a href="https://facebook.com" target="_blank" rel="noopener noreferrer">Facebook</a>
```
Замените на реальные:
```html
<a href="https://instagram.com/lumia_dental_lviv" target="_blank" rel="noopener noreferrer">Instagram</a>
```


### 5️⃣ **Настроить отправку формы на сервер**

В HTML файле найдите (строка ~1748, в JavaScript):

**Вариант А - если у вас есть бэкенд (Node.js, PHP, Python):**

Замените на реальный код:
```javascript
// Отправить на сервер
fetch('/api/contact', {  // или 'https://YOUR-DOMAIN.com/api/contact'
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({ name, phone })
})
.then(response => response.json())
.then(data => {
  if (data.success) {
    alert('✅ Дякуємо! Ми передзвонимо вам найскоріше.');
    closeContactModal();
    contactForm.reset();
  } else {
    alert('❌ Помилка. Спробуйте ще раз.');
  }
})
.catch(error => {
  console.error('Error:', error);
  alert('❌ Помилка сервера. Спробуйте пізніше.');
});
```

## ЗАГРУЗКА НА ХОСТИНГ

### Для хостинга типа Cpanel (1and1, Beget, TimeWeb):
1. Откройте File Manager
2. Перейдите в папку `public_html` (или похожее)
3. Загрузите файл `lumia-dental-final-6.html` (или переименуйте в `index.html`)
4. Загрузите папку с файлами:
   - `og-image.jpg`
   - `favicon.ico`
   - `apple-touch-icon.png`
5. Установите права доступа: 644 на файлы, 755 на папки

### Для GitHub Pages (бесплатно):
1. Создайте репозиторий `username.github.io`
2. Загрузите файлы туда
3. Сайт будет доступен на `https://username.github.io`

### Для Vercel (рекомендуется, бесплатно):
1. Зайдите на https://vercel.com
2. Импортируйте проект с GitHub
3. Разверните в один клик

### Для Netlify (бесплатно):
1. Зайдите на https://netlify.com
2. Перетащите папку с файлами (drag & drop)
3. Будет доступен на `yoursite.netlify.app`

## РЕШЕНИЕ ПРОБЛЕМ

### Сайт не открывается
- [ ] Проверьте что файл загружен в правильную папку
- [ ] Проверьте что домен указывает на правильный сервер
- [ ] Проверьте консоль браузера (F12 → Console) на ошибки

### Форма не отправляет данные
- [ ] Проверьте что код отправки скопирован правильно
- [ ] Откройте F12 → Network → тестируйте форму → смотрите запросы
- [ ] Проверьте что API endpoint доступен (если используется бэкенд)

### Google Analytics не показывает данные
- [ ] Проверьте что GA4 ID правильный (G-XXXXX)
- [ ] Откройте F12 → Console → введите `gtag` — должна быть функция
- [ ] Дождитесь 24 часов (GA обновляет данные не моментально)

### Facebook Pixel не работает
- [ ] Проверьте что Pixel ID правильный
- [ ] Откройте Facebook Pixels Helper расширение (Chrome)
- [ ] Посмотрите там ошибки

### Видео hero не загружается
- [ ] Проверьте что видео файл присутствует
- [ ] Проверьте консоль браузера на ошибки CORS
- [ ] Убедитесь что видео формат поддерживается (MP4)
